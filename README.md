# ECHO

Расширение для Chrome и Яндекс.Браузера, которое записывает встречи в Яндекс.Телемост и автоматически транскрибирует их через Groq Whisper.

## Версия 1.1

Что вошло в обновление за сегодня:

- обновлён бренд: название расширения сменено на `ECHO`, логотип и шапка переработаны;
- переделан главный экран: блок с транскриптом скрыт по умолчанию, основной акцент теперь на промпте для саммари;
- добавлен явный режим просмотра записи из истории с кнопкой `← Назад`;
- история стала удобнее: поиск теперь ищет и по тегам, добавлен выпадающий фильтр по тегам, встречи сгруппированы по дням;
- у встреч появились автогенерируемые названия по содержанию транскрипта;
- добавлены статусы встреч на русском: `Идёт запись`, `Запись сохранена`, `Транскрибируется`, `Готово`, `Ошибка`;
- добавлен блок `Незавершённые записи`, чтобы можно было продолжить транскрибацию сохранённых чанков;
- запись стала надёжнее: аудиочанки сохраняются в IndexedDB сразу, до транскрибации; chunking переведён на ограничение по размеру;
- синхронизирована запись между overlay над созвоном и окном расширения: оба интерфейса теперь видят одно и то же состояние и одинаковый таймер;
- исправлены баги интерфейса, включая двойной шаг таймера и проблемы с восстановлением состояния после открытия панели.

## Возможности

- **Запись встречи** — захватывает аудио прямо из вкладки браузера (микрофон + собеседники)
- **Автотранскрипция** — после остановки записи текст появляется автоматически
- **Промпт для саммари** — готовый текст для дальнейшей обработки в нейросети
- **Сохранение файлов** — аудио (.webm) и текст (.txt) сохраняются в `Загрузки/Telemost Recordings`
- **История встреч** — все предыдущие записи доступны в панели
- **Повторная транскрипция** — если лимит Groq закончился, можно перезапустить без повторной записи
- **Умная кнопка** — появляется поверх окна Телемоста и предлагает начать запись, когда подключаются участники

## Установка

### Chrome

1. Скачай и разархивируй архив с расширением
2. Открой `chrome://extensions`
3. Включи **«Режим разработчика»** (правый верхний угол)
4. Нажми **«Загрузить распакованное расширение»**
5. Выбери папку `telemost-recorder`

### Яндекс.Браузер

1. Скачай и разархивируй архив с расширением
2. Открой `browser://extensions`
3. Включи **«Режим разработчика»**
4. Нажми **«Загрузить распакованное расширение»**
5. Выбери папку `telemost-recorder`
6. При предупреждении нажми **«Всё равно установить»**

## Первый запуск

При первом открытии расширение попросит ввести Groq API ключ.

**Как получить ключ:**
1. Зайди на [console.groq.com](https://console.groq.com)
2. Зарегистрируйся (бесплатно, через Google)
3. Раздел **API Keys** → **Create API Key**
4. Скопируй и вставь в расширение

Транскрипция бесплатна в рамках лимитов Groq (очень щедрые для личного использования).

## Использование

1. Зайди на встречу в Телемосте
2. Нажми иконку 🎙 в панели браузера
3. Нажми **«Начать запись»**
4. По окончании встречи нажми **«Остановить»**
5. Дождись транскрипции → скопируй и вставь в Claude

## Совместимость

Работает в браузерах на движке Chromium: **Chrome, Яндекс.Браузер, Edge, Brave, Opera**.
Safari не поддерживается (нет `tabCapture` API).
